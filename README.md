# probe-week

Results of RedLine Milestone 1.5: twenty real terms pages checked every hour
for seven days (23-30 October 2026) on GenLayer Studio, through a probe
contract, never the treasury. One line per page per round in
`results.jsonl`: unreadable, readable, present, absent (validators agreed),
disagreed (MAJORITY_DISAGREE), or no result (no decided outcome).

Written by `.github/workflows/probe-week.yml` on `main`; the pages and the
runner are in `deploy/probes/week/` there. Never merge this branch.
